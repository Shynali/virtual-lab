# Виртуалды химия зертханасы

7–11-сынып оқушыларына арналған 60 интерактивті зертханалық жұмыс (қазақ және орыс тілдерінде).
Оқушы тіркеліп, өз сыныбының зертханаларын орындайды да, күнделігін мұғалімге жібереді. Мұғалім жазбаша пікір қалдырады (баға қойылмайды).

| Сынып | Зертхана саны |
|---|---|
| 7 | 11 |
| 8 | 10 |
| 9 | 17 |
| 10 | 9 |
| 11 | 13 |

## Рөлдер

- **Оқушы** — мектепті, мұғалімді, сыныбын таңдап тіркеледі; тек өз сыныбының зертханаларын көреді.
- **Мұғалім** — мектебі мен сыныптарын таңдап тіркеледі; бас админ рұқсат бергеннен кейін кіре алады. Оқушылардың жұмысына пікір жазады, ұмытылған құпиясөзді қалпына келтіреді.
- **Бас админ** — мұғалімдерге рұқсат береді, мектептер тізімін басқарады, барлық оқушыны көреді. Өзі де мұғалім ретінде сабақ бере алады («Сыныптарым» бөлімі).

## Сайт қалай жұмыс істейді

- `index.html`, `app.js` — сайттың беті.
- `labs/` — 60 зертхана.
- `core.js` — ортақ логика (тіркелу, кіру, жұмыс жіберу).
- `config.js` — сервердің мекенжайы.
- `api.php`, `lib.php`, `install.php` — PHP + MySQL сервері (ps.kz сияқты хостингке).
- `backend/Code.gs` — Google Apps Script сервері (деректер Google Sheets кестесінде сақталады).

`config.js` ішіндегі `API_URL` бос болса, сайт **үлгі (демо) режимінде** жұмыс істейді: деректер тек сол браузерде сақталады. Демо-режимде бас админ: логин `admin`, құпиясөз `admin123`.

## PHP + MySQL хостингке орнату (ps.kz және т.б.) — ұсынылатын жол

Сайт PHP 7.4+ және MySQL/MariaDB бар кез келген хостингте жұмыс істейді. Сервер файлдары: `api.php`, `lib.php`, `install.php`, `.htaccess`.

1. Хостинг панелінде **MySQL базасы** мен оның **пайдаланушысын** жасаңыз (пайдаланушыға базаға толық құқық беріңіз). База атауын, пайдаланушы атын және құпиясөзін жазып алыңыз.
2. Осы репозиторийдің барлық файлын (`virtual-lab.zip`) сайттың түбір папкасына (`public_html` немесе `httpdocs`) жүктеп, архивтен шығарыңыз.
3. Браузерде `https://сіздің-домен/install.php` бетін ашыңыз:
   - MySQL деректерін (сервер — әдетте `localhost`, база, пайдаланушы, құпиясөз) жазыңыз;
   - бас админнің логині мен құпиясөзін ойлап табыңыз;
   - **Орнату** батырмасын басыңыз. Кестелер мен мектептер тізімі өздігінен жасалады, `config.php` файлы жазылады.
4. Орнатудан кейін `install.php` файлын файл менеджерінен өшіріңіз.
5. `https://сіздің-домен/` бетіне өтіп, админ логинімен кіріңіз.

> `config.js` сайттың қай жерде ашылғанын өзі анықтайды: PHP хостингте `api.php` серверін қолданады, ал GitHub Pages-те үлгі режимінде жұмыс істейді.
> `config.php` және `lib.php` файлдары `.htaccess` арқылы сырттан ашылмайды.

## Google Apps Script серверін қосу (балама жол, ~10 минут)

1. Google Drive-та жаңа **Google Sheets** кестесін ашыңыз (мысалы, «Виртуалды зертхана — деректер»).
2. Мәзірден **Кеңейтімдер → Apps Script** (Extensions → Apps Script) таңдаңыз.
3. Ашылған редактордағы бар кодты өшіріп, осы репозиторийдегі `backend/Code.gs` файлының мазмұнын түгел көшіріп қойыңыз.
4. Код ішінен мына жолды тауып, өз құпиясөзіңізді жазыңыз:
   ```js
   var ADMIN_PASS = "ОСЫНДА_ӨЗ_ҚҰПИЯСӨЗІҢІЗДІ_ЖАЗЫҢЫЗ";
   ```
   (Бұл код тек сіздің Google аккаунтыңызда сақталады, GitHub-қа шықпайды.)
5. **Сақтау** (💾) басыңыз. Жоғарыдағы тізімнен `setup` функциясын таңдап, **Іске қосу (Run)** басыңыз. Google рұқсат сұрайды — өз аккаунтыңызды таңдап, рұқсат беріңіз.
6. **Deploy → New deployment** → түрі: **Web app**.
   - *Execute as*: **Me** (мен)
   - *Who has access*: **Anyone** (кез келген адам)
   - **Deploy** басып, шыққан **Web app URL**-ді (`https://script.google.com/macros/s/…/exec`) көшіріп алыңыз.
7. Осы репозиторийдегі `config.js` файлын ашып (✏️ Edit), URL-ді жазыңыз:
   ```js
   window.LAB_CONFIG = { API_URL: "https://script.google.com/macros/s/…/exec" };
   ```
   **Commit changes** басыңыз. 1–2 минуттан соң сайт нақты сервермен жұмыс істейді.
8. Сайтқа `arailymtoibazarova` логинімен кіріп, **Профиль** бөлімінен құпиясөзді ауыстырыңыз.

> Кодты кейін өзгертсеңіз, **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** арқылы жаңартыңыз (URL өзгермейді).

## Құпиясөзді ұмытса

- Оқушы — мұғаліміне жүгінеді: **Оқушылар → Құпиясөзді қалпына келтіру**. Уақытша 6 таңбалы құпиясөз шығады, оқушы кірген соң жаңасын ойлап табады.
- Мұғалім — бас админге жүгінеді: **Мұғалімдер → Құпиясөзді қалпына келтіру**.
